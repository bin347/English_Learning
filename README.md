# 拾句（英语学习助手）

面向 Windows 的本地英语学习桌面应用。学习记录、导入读物、阅读位置和 API 配置保存在本机，无需注册。

## 安装与运行

Windows x64 用户可下载发行版中的 `英语学习助手 Setup 0.2.5.exe`，运行安装程序后从开始菜单或桌面快捷方式启动。关闭窗口后程序留在系统托盘，可从托盘重新打开或退出。源码运行需要 Node.js/npm：

```powershell
npm ci
npm run build
npm start
```

`npm run dist` 生成安装包；`npm test` 运行服务端回归，`node desktop/tests/popup-race.cjs` 检查划词弹窗异步结果隔离。界面回归脚本 `scripts/ui-smoke.py`、`scripts/media-ui-smoke.py` 只连接隔离测试服务器 8766；不要将测试服务器的数据目录指向正式学习数据。

## 学习功能

- 单词：基础高频、四级、六级、雅思、托福、GRE 词书，使用 ECDICT 标签而非伪造官方考试题库；新词、在学、到期复习、已掌握分开。支持中文填空和选择题；答错的词自动加入生词本并安排复习，熟词直接标记掌握不会加入生词本。填空按词典释义字面比对，未收录的同义表达可手动纠正。复习按 1、3、7、14 天安排，忘记后重新学习；主动掌握可直接移出复习。
- 生词：阅读、划词、翻译与听写产生的候选词均由用户确认收藏，保留原句和来源；重复收藏合并。支持收藏短语复习、返回原文和跨词书到期复习。
- 句子与听力：提供分级练习及带来源说明的真人录音，支持搜索并导入 Tatoeba 双语例句，也可将文章逐句用于练习。句子和听力草稿独立保存在本机，听力支持英文听写及中文理解；评分反馈和历史记录可收起。真人录音和系统朗读明确标注。
- 评分：无 API 时，预设人工关键词提供有限的基础反馈；配置并启用评分用途后使用 API 语义评分。没有关键词的导入句可用于英文听写，中文评分需补关键词或启用 API。基础分数不能判断所有同义表达、否定或语法关系。
- 阅读：TXT、EPUB、粘贴文本，支持搜索导入 Project Gutenberg 名著；Gutendex 在线目录与本地 Gutenberg 书目快照互为补充，正文下载支持官方地址及镜像回退。原地查词、朗读、整句翻译、收藏及加入两种练习；支持字号、行距、背景及本地阅读难度估算。TXT 按阅读框及字号自适应分页，EPUB 支持章节目录；支持左右点击翻页、书签与页码或进度跳转。EPUB 难度针对当前章节，非整本书。
- 新闻：搜索中国日报、新华社英文网及 Global Voices 的英文新闻，在软件内阅读原站；可从原站阅读区导入正文到书架或整篇练习。Global Voices 还提供带来源和许可说明的纯文本阅读。原站加载和正文提取受网站及网络情况影响。
- 翻译：配置并勾选“阅读 / 划词翻译”用途的 API 优先；失败后依次尝试 Bing、Yandex，最后展示词典逐词释义。跨程序句子翻译使用同一顺序。
- API：兼容 OpenAI 接口，地址、模型、可选 Key，以及“阅读 / 划词翻译”“练习评分”两个用途勾选。只有勾选对应用途且配置完整才使用。在线翻译会发送选中文字，语义评分会发送原题和答案至对应服务。
- 影视：支持 MP4/HLS、剧集选择和观影前预习。有可匹配的英文字幕时优先使用影视来源自带字幕，否则查询 SubtitleDB 和备用来源（剧集用 Gestdown，电影用 YIFY Subtitles）。字幕搜索无需账号或 API Key。程序按整集对白和学习记录生成词卡，可选启用 AI 结合原句精选，失败时保留本地词卡。没有字幕时可以使用可选的 AI 题材预热，或直接播放。
- 桌面：关闭窗口后留在托盘。支持的应用选区会显示划词入口；不能自动读取时，复制后按 `Ctrl+Shift+E` 查询。词条与主窗口共用本地记录。
- 备份：导出和恢复读物、EPUB 文件、位置、生词、词库学习进度和练习；备份包含未提交的练习草稿，不包含 API Key；恢复前显示确认，恢复时保留本机已有 Key。
